Module Opencl_plugin_base.For_testing

TEST-ONLY hooks. Nothing in the library sets these; production behaviour never depends on them.

val zero_copy_on_any_device : bool Stdlib.ref

When true, alloc_zero_copy also accepts non-CPU devices, so the CL_MEM_USE_HOST_PTR synchronisation paths can be exercised on a GPU. Test-only: it breaks the production assumption "zero-copy implies a CPU device implies no launch deferral" (Execute.ml, defers_device).
