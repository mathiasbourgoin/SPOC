Module type Transfer.STREAM

Stream handle - packages backend stream with its operations.

stream_ref is the backend stream wrapped by the backend's own wrap_stream, so any other unpacking of the same backend can recover it (Framework_sig.stream_ref). state is this stream's entry in the keep-alive Ledger.

Streams created by create_stream are BLOCKING streams (they synchronise with the device's legacy default stream). The auto-transfer path relies on that: after an async ranged write the vector is Stale_CPU, and the implicit read-back runs on the default stream, which then waits for the write. Switching to non-blocking streams requires making auto-sync stream-aware first (FR-019).
